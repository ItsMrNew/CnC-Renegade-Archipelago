# Developer shortcuts

These scripts cover diagnostics, native tests and save-pack creation. They resolve
the repository root from this folder and require the development Python environment.
They are not needed by players using the standalone EXE.

Some intentionally trigger victories, objectives, damage or death in disposable
rooms. Read their instructions and use the appropriate test room/save. Close the
regular AP launcher before attaching a native diagnostic.

Player shortcuts remain at the repository root; player downloads omit these tools.
